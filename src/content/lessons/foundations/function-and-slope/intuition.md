A **function** turns an input into an output. Drawn as a curve, it shows the height `y` for every position `x`.

The **slope** tells you how steep the curve is at one spot. Walking to the right, a positive slope means you climb, a negative slope means you go downhill, and a slope of zero means the ground is flat for a moment.

Machine learning uses slope all the time. To make a model better, we ask "which way is downhill?" and take a step that way. The slope answers that question.

Try it: move the point along the curve and watch the dashed tangent line. It touches the curve at the point and points the same way the curve does there. Its steepness is the slope. Then switch to a different curve and see how the slope changes.
