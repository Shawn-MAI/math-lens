Imagine a bowl whose position is described by two weights. Each contour line connects points
at the same loss, like a line of equal height on a map. The center is the lowest point.

The gradient has one component for each weight. Both components are measured at the same
starting position, and each weight moves in the opposite direction. The bowl is steeper in
the second direction, so the same learning rate can cause that weight to swing back and forth.
Drag the starting point or use the two weight controls to explore.
